## Title

`VeriBid — Evidence-Driven Bid Evaluation Engine`

## Description (465/512 characters)

VeriBid is an evidence-driven bid evaluation engine for procurement and sourcing teams. It transforms complex RFPs and vendor proposals into a traceable evidence matrix, pairing Amazon Bedrock for semantic reasoning with deterministic tools for rules, thresholds, TCO, and scoring. Conflicts and missing evidence are surfaced transparently, while human reviewers retain final decision authority through an auditable review trail and defensible Markdown/PDF exports.
