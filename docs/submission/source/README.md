# Submission sources

This folder is reserved for redacted source excerpts and captured artifacts
used in the Builder Center article. The current evidence-backed source of
truth is the numbered proof pack in `../../submission-proof/`.

No raw vendor document, secret, token, presigned URL, or unredacted AWS
account identifier should be copied here. Add a source only after checking the
security boundary and recording its relationship in `../claim-register.md`.
